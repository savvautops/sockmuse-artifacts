Rootless does not mean “no root.” It means jailbreak files live outside Apple's sealed system volume,
mainly under /var/jb . You can still obtain a UID 0 shell and run daemons inside the jailbreak environment;
you simply do not rewrite Apple's sealed root filesystem.

Preparation

3/7

03

Install TrollStore with TrollRestore

This is the only stage that needs a computer. TrollRestore restores a
deliberately modified backup that places the TrollStore helper inside a
removable Apple system app.
1

Download TrollRestore
Open the official TrollRestore releases page. On Windows, download TrollRestore.exe . On
Apple silicon macOS, choose the arm64 archive; on Intel macOS, choose amd64; on Linux, choose
the Linux archive.

2

Connect and trust the phone
Unlock the iPhone, connect it by USB, accept Trust This Computer, and leave the phone
connected. Find My must already be off.

3

Run TrollRestore
On Windows, double-click the executable. If Windows SmartScreen appears, verify the file came from
the JJTech0130 GitHub release page before allowing it. Do not substitute a mirror.

4

Choose Tips
When prompted for the system app to overwrite, enter Tips . The phone may look idle while the
restore runs. Do not unplug it. The phone will reboot when the helper has been injected.

5

Install TrollStore
After reboot, unlock the phone and open Tips. Tap Install TrollStore. The interface will respring and
TrollStore should appear on the Home Screen.

6

Add persistence, then restore Find My
Open TrollStore → Settings → Install Persistence Helper → Tips. Once TrollStore opens normally,
turn Find My back on.

If Tips is missing: reinstall Tips from the App Store, reboot, and run TrollRestore again. If the computer
cannot see the phone, unlock it, re-accept Trust, try another cable/USB port, and reopen iTunes or Apple
Devices.

TrollRestore → TrollStore

4/7

04

Install Dopamine and jailbreak

TrollStore keeps the jailbreak app installed. Dopamine applies the jailbreak
and creates the rootless environment under /var/jb .
1

Download the official IPA
On the iPhone, open Dopamine Releases and download the current IPA that explicitly supports A9
and iOS 15.8.8. A9 support began in the 2.5 beta line; a newer compatible release is preferable to an
old stable build.

2

Install through TrollStore
Open TrollStore → + → choose the downloaded Dopamine .ipa in Files → Install. Dopamine
should appear on the Home Screen without seven-day re-signing.

3

Start from a clean reboot
Reboot the phone, unlock it, then open Dopamine immediately. Select Sileo as the package manager
and create a strong sudo password when prompted. Save it in a password manager; it is not your
Apple Account password.

4

Run the exploit
Tap Jailbreak. The device will respring or userspace-reboot. When it returns, look for Sileo. If
Dopamine closes or the phone restarts before completion, reboot and try again; DarkSword can fail a
race and the official release notes call this out.

5

Finish the bootstrap
Open Sileo, refresh sources, and install all essential updates. The maintained guide then installs or
updates ElleKit and PreferenceLoader, followed by a SpringBoard restart. Reboot and re-jailbreak if
tweak injection does not initialize cleanly.

Success looks like this: Dopamine reports jailbroken, Sileo opens, packages refresh without fatal errors,
and /var/jb exists. Stop here before adding tweaks; confirm the base stays stable first.

Harden SSH before making it a node

Remote shell access is useful and dangerous. Install it only after the jailbreak
is stable, and never expose port 22 directly to the public internet.

On the iPhone
1. In Sileo, install OpenSSH Server and an ondevice terminal such as NewTerm.
2. Use the strong sudo password created during
Dopamine setup. If your bootstrap still has a
default password, change it immediately.
3. Find the phone's LAN or private-overlay IP. Keep
SSH limited to a trusted LAN or private network
such as Tailscale.

Do not: port-forward TCP 22 from the router, reuse
an Apple Account password, or paste private keys
into random tweak prompts.

From your computer
ssh mobile@PHONE_IP
sudo -i
id -u
# expected: 0

Prefer SSH keys after the first successful login. Keep
the private key on your computer and add only the
public key to the phone.

mkdir -p ~/.ssh
chmod 700 ~/.ssh
# append your public key only
chmod 600 ~/.ssh/authorized_keys

About “root.” UID 0 is real, but Apple's sealed system volume remains protected. Build for the rootless prefix
( /var/jb ) and install rootless packages marked for iphoneos-arm64 . Old rootful tweaks that hard-code
/Library or /usr can break the environment.

When something fails

1. The phone boots in normal, non-jailbroken mode.

Dopamine closes

2. Open Dopamine.

Reboot and retry. The release notes acknowledge
occasional DarkSword failures.

3. Tap Jailbreak.
4. Wait for the respring/userspace reboot.
5. Confirm Sileo and SSH again.
This is the convenience advantage over palera1n:
routine recovery does not require DFU mode or a
computer.

Boot loop fear

Force a normal reboot; a semi-untethered jailbreak
should return to stock mode.
A tweak causes crashes

Use Dopamine's safe-mode or disable-tweakinjection option, then remove the last package.
SSH disappears

Re-apply Dopamine first; jailbreak daemons are not
active in stock mode.

Do not auto-update blindly
A later iOS update can remove or break the jailbreak even though checkm8 remains available as a hardware
fallback. Before installing any future update, check the Dopamine release notes for the exact device, chip, and
build. The trade-off is real: delaying updates preserves jailbreak compatibility but also delays security patches.

Next Nano Nodes phase: OpenClaw-iOS
Once the phone survives a reboot/re-jailbreak cycle and SSH is reliable, the next experiment is a
rootless .deb under /var/jb . The OpenClaw-iOS project targets iOS 15 arm64 with
Dopamine/Procursus, bundles Node.js, and defines a launchd service. Treat it as experimental: its own
project notes have tracked active end-to-end work, so validate the current release status before relying
on it.
