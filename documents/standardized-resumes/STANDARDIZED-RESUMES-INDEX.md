# Standardized Resume Library

Use this page as the front door for Nelson's base resumes. Each role family has:

- `.md` — easiest source to edit in Obsidian or any text editor.
- `.docx` — editable in Microsoft Word, Google Docs, or LibreOffice.
- `.pdf` — ready to review or upload after tailoring.

These are truthful base resumes, not final employer-specific applications. Before applying, tailor the target title, summary, keywords, and most relevant bullets to the actual posting. Do not invent tools, employment, metrics, or experience.

## Tailoring workflow

1. Choose the closest role-family base.
2. Duplicate it into the application package; never overwrite this base for one employer.
3. Match the employer's language only where it is truthful.
4. Move the three most relevant skills and accomplishments to the top.
5. Remove irrelevant material rather than adding keyword soup.
6. Render and visually inspect the final PDF before approval or upload.
