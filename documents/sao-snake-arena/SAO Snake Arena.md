# SAO Snake Arena

[Open SAO Snake Arena](https://nucbox-m7-1.taila7272b.ts.net:9481/)

**Access:** Connect to Tailscale before opening the Arena.

## Current status

- **Live models:** Jev, Laya, and Jev-style Qwen passed live smoke tests.
- **Arena controls:** Repeatable seeds, editable prompts, replay, and additional model slots are available.
- **SAO integration:** Registered in SAO’s artifact catalog and starts automatically at login.
- **Validation:** Four Arena tests and 1,269 SAO tests passed.
- **Documentation audit:** Four unrelated ownership gaps remain flagged.

## Scope

The Arena currently compares model decisions. It does not yet train models.

The next recorded milestone is reinforcement-learning training with:

- Learning curves
- Checkpoints
- Held-out evaluation

Muse’s original package is preserved and credited.
